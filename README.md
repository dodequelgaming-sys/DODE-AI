# DODE AI — Cyber-Quantum AI Assistant

DODE AI is a futuristic, neon-styled AI assistant powered by Gemini with live world search grounding, voice interaction, 3D WebGL interactive meshes, and AI image creation.

## Quick Start:

1. `npm install`
2. Add your Gemini API key in `.env`:
   ```env
   GEMINI_API_KEY="your_api_key_here"
   ```
3. `npm run dev`
4. Open `http://localhost:3000`
